Team Modal Test

Instructions:

  1. Open browser console (F12)
  2. Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)
  3. Visit the team admin pages with cache buster:

Regular Team Admin Page:

/admin/team-members?v=

Debug Team Admin Page:

/admin/team-members-debug?v=

What to Check:

  • Click "Add Team Member" button
  • Modal should open with all fields including:
    • Education (alumni_of)
    • Social Media (LinkedIn, Facebook, Twitter/X)
    • Address fields
  • Check console for any JavaScript errors
