## Common Issues & Solutions

### Recent Fixes (August 2025)

#### 1. Missing Keywords Meta Tags

**Issue**: SEO tools couldn't detect keywords
**Solution**:

- Added keywords prop to Layout.astro
- Implemented page-specific keywords
- Created seo-keywords.ts database

#### 2. Sitemap Configuration Conflicts

**Issue**: Robots.txt pointed to wrong sitemap URL
**Solution**:

- Removed Astro sitemap plugin
- Updated robots.txt to /sitemap.xml
- Fixed sitemap generation logic

#### 3. Admin Pages in Sitemap

**Issue**: Private pages being indexed
**Solution**:

- Added exclusion rules in sitemap.xml.ts
- Filtered admin paths from generation
